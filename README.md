# QuickNotes

QuickNotes is a simple browser-based note-taking application built with HTML, CSS and JavaScript.

## Features

- Add notes with a title, content and category.
- Validate required fields and input lengths.
- Search notes by title, content or category.
- Delete individual notes.
- Save notes in browser `localStorage`.
- Restore saved notes when the page is reopened.
- Responsive layout for desktop and mobile screens.

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser DOM API
- Browser `localStorage`

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Create, search and delete notes.

No additional dependencies or installation are required.

## Data storage

Notes are stored locally in the browser under the key `quicknotes-notes`. They are not automatically synchronized across devices or browsers. Clearing browser storage may remove saved notes.

## Project structure

- `index.html` — application structure.
- `style.css` — layout and visual styling.
- `script.js` — note management, search and persistence.
- `README.md` — project documentation.
